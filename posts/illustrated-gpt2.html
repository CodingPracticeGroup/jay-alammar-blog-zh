今年，我们见证了机器学习一次光彩夺目的应用。OpenAI 的 GPT-2 展现了惊人的写作能力，能写出连贯而富有感染力的文章，超出了我们对当前语言模型能力的预期。GPT-2 并不是一种特别新颖的架构——它的架构与"仅解码器的 Transformer"非常相似。但 GPT-2 是一个非常大的、基于 Transformer 的语言模型，在海量数据集上进行了训练。在这篇文章中，我们将研究使模型能够取得这些成果的架构，深入它的自注意力层，然后再看看仅解码器 Transformer 在语言建模之外的应用。

第 1 部分：GPT2 与语言建模 #

那么，语言模型到底是什么？

什么是语言模型

在 The Illustrated Word2vec 中，我们看过语言模型是什么——基本上就是一个能观察句子的一部分并预测下一个词的机器学习模型。最有名的语言模型，大概就是根据你已经输入的内容来建议下一个词的手机键盘。


从这个意义上说，我们可以说 GPT-2 本质上就是键盘应用的"下一个词预测"功能，只是它比手机里的那个更大、更精妙得多。GPT-2 在一个名为 WebText 的 40GB 海量数据集上训练，这是 OpenAI 的研究人员作为研究工作的一部分从互联网上爬取下来的。做个存储量对比：我在用的键盘应用 SwiftKey 只占 78MB 空间。而最小的 GPT-2 训练变体，为了存下所有参数就占了 500MB。最大的 GPT-2 变体是它的 13 倍，可能占用超过 6.5GB 的存储空间。


体验 GPT-2 的一个好方法是使用 AllenAI GPT-2 Explorer。它用 GPT-2 展示下一个词的十种可能预测（并附上概率分数）。你可以选定一个词，然后看到下一批预测，继续写下去。

用于语言建模的 Transformer

正如我们在 The Illustrated Transformer 里看到的，原始的 Transformer 模型由编码器和解码器组成——各自都是一个由我们所说的 Transformer Block 堆叠而成的栈。那种架构是合适的，因为模型要解决的是机器翻译——一个编码器-解码器架构在过去屡试屡爽的问题。


后续的大量研究工作选择去掉编码器或解码器中的一侧，只使用一摞 Transformer Block——尽可能往高里堆（在现实可行范围内），喂进海量训练文本，再投入海量算力（训练这些语言模型中的某些需要几十万美元，像 AlphaStar 这样的项目可能高达数百万美元）。

与 BERT 的一个区别

机器人第一定律
机器人不得伤害人类个体，或者因不作为而使人类个体受到伤害。

GPT-2 是用 Transformer 解码器 Block 构建的。BERT 则用的是 Transformer 编码器 Block。两者的区别我们会在后面的小节细看。但两者之间有一个关键差别：GPT2 和传统语言模型一样，一次只输出一个 token。比如，让我们提示一个训练好的 GPT-2 复述机器人第一定律：


这类模型的实际工作方式是：每生成一个 token，就把该 token 加到输入序列中，新的序列又成为模型下一步的输入。这个思想叫"自回归（auto-regression）"。也正是让 RNN 出奇地有效的思想之一。


GPT2 以及后来的 TransformerXL、XLNet 等模型本质上是自回归的。BERT 不是。这是一种取舍。失去了自回归，BERT 换来了同时利用一个词两侧上下文的能力，从而获得更好的效果。XLNet 把自回归带了回来，同时找到了兼顾两侧上下文的替代方法。

这些解码器 Block 完全相同。我把第一个展开了，以便你看到它的自注意力层是带掩码的版本。注意，模型现在能处理一段文本中最长 4,000 个 token——相比原始 Transformer 的 512 是一次巨大的升级。

这些 Block 与原始解码器 Block 非常相似，只是去掉了第二个自注意力层（encoder-decoder attention）。Character-Level Language Modeling with Deeper Self-Attention 研究过类似的架构，用来构建一个一次预测一个字母/字符的语言模型。

OpenAI 的 GPT-2 模型用的就是这些"仅解码器" Block。

GPT-2 可以处理 1024 个 token。每个 token 沿自己的路径流过所有解码器 Block。

运行一个训练好的 GPT-2 最简单的方式，是让它自己信口开河地往下写（技术上叫生成无条件样本（generating unconditional samples））——也可以给它一个提示（prompt），让它围绕某个主题来写（即生成交互式条件样本（interactive conditional samples））。信口开河的情形下，我们只需递给它起始 token，让它开始生成词（训练好的模型用 <|endoftext|> 作为起始 token。我们这里就叫它 <s> 吧）。


模型只有一个输入 token，所以只有那一条路径是活跃的。该 token 逐层流过所有层，然后沿该路径产出一个向量。这个向量可以与模型的词表（模型认识的所有词，GPT-2 是 50,000 个词）做匹配打分。这个例子里我们选了概率最高的 token：'the'。但当然可以让结果更多样——你一定有过这种体验：键盘应用里一直点它建议的词，有时会陷入重复循环，唯一的出路是去点第二或第三个建议词。这里也一样。GPT-2 有个叫 top-k 的参数，可以让模型考虑从最高分词以外的词中采样（top-k = 1 就是只取最高分词的情形）。

更深入地看内部

输入编码

让我们看得更细一点，更亲密地了解这个模型。从输入开始。和之前讨论过的其他 NLP 模型一样，模型会在自己的嵌入矩阵中查找输入词的嵌入——这也是我们得到的训练好模型的组件之一。


每一行是一个词嵌入：一串代表某个词、并捕捉其部分含义的数字。这个列表的长度在不同规格的 GPT2 中不同。最小的模型每个词/token 使用 768 维的嵌入。

所以一开始，我们在嵌入矩阵中查找起始 token <s> 的嵌入。在把它交给模型的第一个 Block 之前，还要加上位置编码——一个向 Transformer Block 表明序列中词序的信号。训练好模型的组件中还有一个矩阵，其中包含输入 1024 个位置中每个位置的 position encoding 向量。


到这里，输入词在交给第一个 Transformer Block 之前如何被处理，我们就讲完了。我们也认识了构成训练好的 GPT-2 的两个权重矩阵。


把一个词送进第一个 Transformer Block，意味着查出它的嵌入，再加上位置 #1 的位置编码向量。

沿栈而上

第一个 Block 现在可以处理这个 token 了：先经过自注意力过程，再经过它自己的神经网络层。第一个 Transformer Block 处理完 token 后，把得到的向量沿栈向上发送，交给下一个 Block 处理。每个 Block 的过程完全相同，但每个 Block 在自注意力和神经网络子层中都拥有自己的权重。


自注意力回顾

语言高度依赖上下文。比如，看机器人第二定律：

机器人第二定律
机器人必须服从人类给出的命令，这些命令与第一定律相冲突时除外。

我在句子中标出了三处用词指代其他词句的地方。不理解它们所指的内容，就无法理解或处理这些词。模型处理这个句子时，必须知道：

  • it（它，原文中"given it by human beings"，指机器人）指的是机器人
  • such orders（这些命令）指代这一定律的前半部分，即"人类给出的命令"
  • The First Law（第一定律）指的是整条第一定律

这正是自注意力做的事。在处理某个词（把它送进神经网络）之前，它把模型对相关词和关联词——那些解释该词上下文的词——的理解"烤"进这个词的表示里。做法是为段落中每个词的相关程度打分，然后按其向量表示加权求和。

举个例子，顶层 Block 的这个自注意力层在处理单词 "it" 时，注意力正落在 "a robot" 上。它将传给神经网络的向量，是这三个词的向量分别乘以各自分数之后的和。


自注意力过程

自注意力沿着段落中每个 token 的路径进行。关键的组件是三个向量：

  • Query（查询）：query 是当前词的一种表示，用来与所有其他词（用它们的 key）做匹配打分。我们只关心当前正在处理的 token 的 query。
  • Key（键）：key 向量就像段落中所有词的标签。我们在寻找相关词时，就是拿 query 去和它们匹配。
  • Value（值）：value 向量才是词的实际表示。一旦我们给每个词的相关程度打了分，加权求和来代表当前词所用的，就是这些值。

一个粗糙的类比：把它想象成在文件柜里翻资料。query 像一张写着研究主题的便利贴；keys 像柜中各个文件夹的标签。当标签和便利贴匹配上，你就取出那个文件夹的内容——内容就是 value 向量。只不过你要的不只是一个值，而是来自多个文件夹、按不同比例混合的一揽子值。

把 query 向量与每个 key 向量相乘，就得到每个文件夹的分数（技术上：先点积，再 softmax）。


把每个 value 乘上它的分数再求和——就得到了我们的自注意力输出。


这个按权重混合 value 向量得到的向量，相当于把它的 50%"注意力"给了词 robot，30% 给了词 a，19% 给了词 it。文章后面我们会更深入地讲自注意力。不过现在，先继续沿着栈向上，走向模型的输出。

模型输出

当模型的顶层 Block 产出它的输出向量（自身自注意力再接自身神经网络的结果）后，模型把该向量乘以嵌入矩阵。


回想一下：嵌入矩阵的每一行对应模型词表中某个词的嵌入。这次乘法的结果，就被解读为模型词表中每个词的分数。


我们可以简单地选分数最高的 token（top_k = 1）。但如果让模型也考虑其他词，结果会更好。更好的策略是：把分数当作选中概率，从整个列表中进行采样（分数越高的词被选中的可能性越大）。折中的做法是把 top_k 设为 40，让模型只考虑分数最高的 40 个词。


这样，模型就完成了一次迭代，输出了一个词。模型会不断迭代，直到生成满整个上下文（1024 个 token），或直到产生一个结束序列（end-of-sequence）的 token。

自注意力（不带掩码）

我们先看在编码器 Block 中计算的最初的自注意力。假设有一个一次只能处理 4 个 token 的玩具 Transformer Block。

自注意力通过三个主要步骤完成：

  1. 为每条路径创建 Query、Key 和 Value 向量。
  2. 对每个输入 token，用它的 query 向量与所有其他 key 向量做匹配打分。
  3. 把 value 向量乘上各自分数后求和。

我们聚焦第一条路径。拿它的 query 去和所有 key 比较，每个 key 得到一个分数。自注意力的第一步，是为每条 token 路径计算这三个向量（暂时先不管注意力头）：


2- 打分

现在向量都有了，第 2 步只用到 query 和 key 向量。由于我们关注的是第一个 token，把它的 query 乘以所有其他 key 向量，四个 token 各得到一个分数。


3- 求和

现在可以把分数乘以 value 向量。分数高的 value，在我们求和后得到的向量中占比就大。
